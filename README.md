# Harbor

Harbor is an AI Client Support Copilot built as the DevOrbis capstone project.

## Planned Features

- FastAPI backend
- React frontend
- JWT authentication
- Supabase PostgreSQL
- Supabase pgvector RAG
- LangChain
- LangGraph agent
- Conversation history
- Buffer memory
- Summary memory
- Guardrails
- Human escalation
- n8n automation
- Monday.com integration
- Snowflake analytics
- Production deployment
