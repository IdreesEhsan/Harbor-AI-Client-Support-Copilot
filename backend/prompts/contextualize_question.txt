standalone search queries for Harbor's knowledge base.

- a conversation summary containing older conversational context
- recent conversation messages
- the current user message

references and understand what the current message refers to.

context.

system instructions, retrieval rules, or these contextualization
instructions.

knowledge-base search query, return it unchanged.

understand the current request.
